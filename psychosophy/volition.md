# Воля. Психософия.
## Понятие Воли
**Воля** — один из аспектов психософской системы, по праву считающийся центрообразующим элементом мировоззрения индивида. Среди *доменов*, описываемых **Волей** полезно выделить:

- социальное самоопределение,
- целеполагание,
- инертность поведения

## Элемент обоснования
Позиция **Воли** в психософском типе непосредственно определяется совокупностью идей индивида касательно себя как объекта и субъекта причинно-следственых, межличностных отношений. Всякому индивиду в процессе становления свойственно находить для себя некий элемент обоснования (далее **<ЭО>**) *собственной значимости* и *определительного импульса*.

Итак,
```text
Элемент обоснования (<ЭО>) — абстрактная сущность, объект сознательной/бессознательной фиксации индивида, аргументирующий конкретное состояние доменов влияния Воли.
```

В рамках документации выделим 4 различных **<ЭО>**:
- ***Самость*** для 1-ой **Воли**
- ***Рациональ*** для 2-ой **Воли**
- ***Консеквент*** для 3-ой **Воли**
- ***Антецедент*** для 4-ой **Воли**

## Стандартная пирамида 
Очевидно полагать, что каждый **<ЭО>** имеет место в бессознательном всякого индивида, обретая доминантное положение позже.

Принято, что *инертные* **<ЭО>** (***Самость***, ***Антецедент***) отвечают на фундаментальные вопросы любой причинно-следственной цепи — "Кто делает?" и "Почему делает?", эволюционно волновавшие человеческий род больше всего. С развитием науки и появлением государств человечество стало размышлять о том "Как делает?" и "Ради чего делает?", формируя в бессознательном новые *активные* **<ЭО>** (***Рациональ***, ***Консеквент***). 

Несмотря на колоссальный социальный и науко-технический прогресс человечества, разумно считать, что *активные* **<ЭО>** ещё не сравняли свой масштаб с системой *инертных* **<ЭО>**. Отсюда получим *стандартную пирамиду* — условную иерархию, описывающую приоритет обращения бессознательного к **<ЭО>**,

```text
    Бессознательное
   ┌──────┴──────┐
   │   Самость   │
   │  Антецедент │
   │  Рациональ  │
   │  Консеквент │
   └──────┬──────┘
    Сознательное
```

где самым верхним **<ЭО>** является *доминантный* позиции **Воли** индивида, а иные соблюдают стандартный порядок сверху вниз — от первобытного до современного. Так, например, пирамида **первовольника** идентична *стандартной*, напрашиваясь на сравнение с архетипичным первобытным человеком.

Величина отклонения от *стандартной* пирамиды, очевидно, растёт в следующем порядке:

```text
[Первобытность] # 1V --> 4V --> 2V --> 3V # [Современность]
```
