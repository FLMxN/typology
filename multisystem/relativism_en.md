# Relativistic approach. Correlations.
## 1. Fundamentals of Correlation Analysis

Inter-system correlation is a principle of the practical application of typologies, based on the premise that not every combination of types can describe a single individual.

The theoretical framework under consideration relies on Socionics' Model A, Claudio Naranjo's Enneagram theory, and A. Yu. Afanasyev's Psychosophy theory.

The basic principle is as follows: if two types are incompatible regarding a specific trait, they cannot simultaneously apply to the same individual. Let us denote a trait or a dichotomy pole as `П`.

Then:

```text
П(A) ≠ П(B) => A ≠ B
```

For example, if the trait `Volition` signifies social self-determination or goal-setting, then the mismatch of this trait between the Enneatype `SX7` and the Psychosophy type `ELVF` leads to the conclusion that these types cannot form a combination within a single system (individual):

```text
Volition(SX7) ≠ Volition(ELVF)  →  SX7 ≠ ELVF
```

Correlations can link more than just two systems. If a correspondence is established between types across three systems, a connection can also be inferred between any two of them. Let `≡` denote "is equivalent to."

Then:

```text
SLI ≡ SP9 ≡ FLEV => SLI ≡ FLEV
```

In this example, the Enneagram serves as the connecting link. A direct comparison between Socionics and Psychosophy is not used within this approach due to significant differences between the domains of individual character described by these systems. 

## 2. The Relativistic Approach

The relativistic approach expands the methodology of correlation analysis by heuristically positing the equivalence of:

- **duality** in Socionics;
- **complete agape** in Psychosophy.

Mapping these relationships allows for the construction of non-obvious type combinations. When determining the Enneagram subtype, it is preferable to rely on the Psychosophic type rather than the Socionic one.

### Initial Sets

- **Reference set (`&`)** — a selected working combination of three types. It is advisable to use an archetypal, indisputable combination (based on consensus) to minimize the risk of error (e.g., **LSE SO1 VLFE**).
- **Target set (`⁂`)** — an incomplete combination in which one of the types remains to be determined. It may include:
1. the Socionic dual of & and the Psychosophic complete agape corresponding to that dual; 
2. the Psychosophic complete agape of & and the Enneagram subtype correlating with it.

### Let & = SEI SX9 FELV

#### Target set (⁂): Socionic dual and Psychosophic agape (1)

The dual of SEI is ILE; the complete agape for FELV is VLEF:

```text
⁂: ILE [X] VLEF
&: SEI SX9 FELV
```

If we accept the correspondence `VLEF ≡ SO7` and prioritize the Psychosophic type when determining the subtype, then `[X] = SO7`. This yields the archetypal combination **ILE SO7 VLEF**.

#### Target set (⁂): Psychosophy agape and Enneagram subtype (2)

```text
⁂: [Y] SO7 VLEF
&: SEI SX9 FELV
```

One should not directly assume `SO7 ≡ ILE` without verification; such an identification might not align with the traits and dichotomies. However, Socionics(&) = **SEI**, and its dual is ILE. Using additional information, we determine `[Y] = ILE`, resulting once again in **ILE SO7 VLEF**.

### Application examples

#### Determining the Enneagram subtype via Psychosophy type

```text
⁂: IEE [V] VELF
&: SLI SP9 FLEV
```

From (1): `[V] = SO2`. The result is **IEE SO2 VELF**. This combination is not immediately obvious, but it is considered possible within the relativistic approach.

#### Determining the Socionics type via duality

```text
⁂: [Q] SO2 VEFL
&: ILI SP5 LFEV
```

Socionics(&) = **ILI**; its dual is SEE. From (2): `[Q] = SEE`, and the Target set becomes **SEE SO2 VEFL**. Accepted.
